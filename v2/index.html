02 / simulate

simulate

  • Block copolymer phase separation
  • Weeks-Chandler-Andersen potential in LAMMPS
  • RIT Honors research, Dr. Padmanabhan, 2020

My first real research was a simulation, not a machine. Block copolymers separate into holes, spheres, stripes, or lamellae depending on their chemistry, and lithography uses those shapes. I wrote about a hundred lines of molecular dynamics with the Weeks-Chandler-Andersen potential and ran thousands of them on RIT's cluster. Temperature, repulsion, and atom size each push the result around, so the point was to find where to start in the lab instead of guessing with expensive runs.

Simulation bridged to experiment.

Designed

The same system settles into holes, spheres, stripes, or lamellae. Which pattern you get is the whole design space.

Analyzed

About 100 lines of molecular dynamics, WCA potential, run in LAMMPS on the RIT cluster across thousands of cases.

Built
no rig

The build here is the simulation itself. No physical rig.

Proved

The runs reached clean separated end states. The interaction parameter falls with temperature and rises with repulsion, a starting map for the lab.

03 / make

make

  • Fusion 360 negative mold
  • Truncated-octahedron lattice in nTopology
  • Transient CFD at 1273 K, RIT AMPrint

This one turns a printed shell into a metal part. In Fusion 360 I built the negative mold with pour holes up top and drains at the bottom, then tilted the whole thing 2 degrees so a 90 degree overhang stayed printable. To keep the ceramic shell from warping in the kiln, I grew a truncated-octahedron lattice in nTopology with most struts running vertical. Before melting anything, I simulated the pour.

Molten aluminium into a printed ceramic mold.

Analyzed

04 / build

build

  • PrintNC steel frame, Fusion 360

  • 1200 by 800 mm work area

I wanted a machine that could cut real material, not foam and patience, so I built a PrintNC in my apartment. On the third floor. Don't tell my landlord. Rigidity comes from steel, so I cut and tapped the members for a stiff frame. The 2.2 kW spindle throws a lot of electrical noise, so I planned a line filter, shielded cable, and a single star ground to keep it out of the logic.

1200 by 800 mm, holds 0.1 mm.

Analyzed

05 / software

software

  • STL to G-code in Python and PyQt
  • Every stage exposed, not hidden
  • Foundation for tilted-plane slicing

I got tired of treating my slicer like a black box, so I wrote my own in Python. You load an STL, set a layer height, then slice and generate G-code, and each stage shows its own state instead of hiding it. Every layer is computed and drawn, so I can check the wall paths at any height. Doing it from scratch is humbling. Every smooth print is hiding a stack of geometry decisions you never had to think about.

STL to G-code, written from scratch.

Designed

A small pipeline that exposes every stage. Load an STL, set layer height and resolution, slice, generate.

Analyzed

Every layer is computed and drawn, so I can see the wall paths and check geometry at each height.

Built

The working program slices a real STL and writes G-code end to end.

Proved

It generates usable G-code from an arbitrary STL. It's the base for research on tilted and curved slicing planes, which is why I wrote it.

02 / simulate

Polymer Lithography Simulation

RIT Honors research, Dr. Padmanabhan, 2020. LAMMPS.

Designed

Depending on the block ratio and chemistry, the same system settles into holes, spheres, stripes, or lamellae, and those shapes are what lithography then uses. The design space is which pattern you get.

Analyzed

The model is about 100 lines of molecular dynamics using the Weeks-Chandler-Andersen potential, run in LAMMPS on the RIT research cluster. Temperature, repulsion strength, and atom size each push the outcome chaotically, so we ran thousands of simulations to find where to start experiments instead of running expensive lab runs blind.

Built

The build here is the simulation itself, the WCA model and its LAMMPS runs. No physical rig.

Proved

The runs reached clean separated end states, and the results showed the interaction parameter falls with temperature and rises with repulsion strength. That's a starting map for the lab instead of a blind search.
