02 — Selected Work

Production systems, in the field.

Vehicle systems I’ve led from concept and validation through to deployment.

  1. 001

    Performance Stability System

    Stability · Controls

    A control system that supports operators in unstable conditions without over-limiting the vehicle — preventing load spillage while keeping performance available when it’s safe to use.

  2. 002

    Smart Environment Sensor Plus (SEnS+)

    ML Vision · Braking

    Stereoscopic camera detection for pedestrians and obstacles, integrated with regenerative braking. ML-based perception tied directly to the vehicle’s safety stack.

  3. 003

    Hydraulic Weight Sensing

    Hydraulics · Signal Processing

    Real-time load weighing using pressure transducers built into the hydraulic manifold. Drives operator display feedback and automatic speed reduction under overload.

  4. 004

    Steer Differentiation System

    Sensors · Geometry

    Real-time refinement of steering geometry using high-fidelity sensor resolution — tighter handling envelopes without compromising the operator feel.

  5. 005

    Interface Logic & Access Control

    UX · Safety

    Re-architected the vehicle menu system around safety classes and operator access levels — making the right action obvious and the wrong action hard.

  6. 006

    Structural Frame Redesign

    FEA · Fatigue

    Tractor frame redesigned for infinite fatigue life. FEA-driven, validated with strain gauges in the field — failure modes designed out before they reached customers.

03 — About

Engineering, end‑to‑end.

I lead engineering work on vehicle systems — stability, hydraulics, perception, structural — and care most about the moments where research has to become a product. The interesting problems sit at the seams: between sensors and control logic, between an FEA model and a field strain gauge, between an ML pipeline and a brake actuator.

Before this, I built things on my own: a 3D slicer in Python to explore non-standard print orientations, flight dynamics simulations in Simulink, a vacuum cannon model, a double pendulum study with a physical rig, a full PrintNC build. The pattern is the same — model it, instrument it, prove it.
